# Upstream components

- Xash3D FWGS: https://github.com/FWGS/xash3d-fwgs — GPLv3 and upstream component notices. This repository supplies a patch against the pinned upstream version; preserve those notices when distributing a compiled engine.
- HLSDK Portable: https://github.com/FWGS/hlsdk-portable — Valve SDK license and upstream build-file notices. Valve game assets are not included.
- SDL2: https://github.com/libsdl-org/SDL — zlib license.
- FUSE 2: https://github.com/libfuse/libfuse — LGPLv2.1/GPLv2 components.
- squashfuse: https://github.com/vasi/squashfuse — BSD-style license.
- XZ Utils: https://tukaani.org/xz/ — upstream component-specific licenses.
- X.Org Xvfb/X11/XTest and zlib come from the separately prepared base environment.
- GCC runtime libraries use their upstream licenses and runtime exceptions.
- `station.py` is reused from the author's YandexMCStation project.

No Valve game data, firmware dumps, private accounts or model/API credentials are published here. This repository does not grant rights to those materials.
